아테나 서버 연동 검사

현재 열어둔 아테나 창을 유지한 상태에서 진행하세요. 1·2번은 로그인과 목록 조회이며, 3번은 선택한 이미지 한 장을 실제 등록합니다.

검사 준비 완료

조회 성공 후: 기존 아테나 창을 새로고침해 로그인이 유지되는지 확인해주세요. 이 화면에서는 브라우저 쪽 로그인 유지 여부를 자동 판정할 수 없습니다.

2차: 기존 이미지 한 장 등록

프로필에서 이미 생성한 이미지를 선택하세요. 새 AI 이미지를 생성하지 않습니다. 기존 프로필의 수동 다운로드·URL 입력 기능은 그대로 사용할 수 있습니다.

등록 후 두 이미지가 같은지 확인하세요. ‘같은 이미지 결과 확인’을 눌렀을 때 기존 결과 재사용 안내가 나오고 아테나 등록 건수가 늘지 않아야 합니다. 이번 단계는 URL 확보까지이며 프로필 자동 반영은 다음 단계입니다.

비밀번호는 인증 요청에만 사용합니다. 아테나 쿠키는 서버 메모리에 최대 15분 보관하며 브라우저·파일·로그로 전달하지 않습니다. 창을 닫기 전에 ‘검사 세션 종료’를 눌러주세요.
